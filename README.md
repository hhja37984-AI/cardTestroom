# Card Testroom

RP 장면을 위한 수동 편집형 블랙잭 샌드박스. LLM 출력을 자동 파싱하지 않습니다. 이전 서사의 패를 사용자가 직접 입력하고, 원하는 인물의 행동만 진행해 결과를 다음 턴에 활용합니다.

## 실행

`index.html` 파일을 브라우저에서 엽니다. 웹 배포는 GitHub 저장소의 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다.

## 이용 방법

1. 기존 장면에서 시작하려면 딜러와 각 참가자의 **+** 버튼으로 카드를 배치합니다. 각 카드를 눌러 편집하거나 ×로 제거합니다.
2. 새로 게임을 시작하려면 **새 패 배분**을 누릅니다. 기존 패를 직접 설정할 때는 **패만 초기화**를 사용하면 칩 잔액이 유지됩니다.
3. 참가자를 추가하고 이름을 변경할 수 있습니다. **Hit / Stand / Double**을 수동으로 선택하거나 **자동 선택 1회**를 누릅니다.
4. 참가자들이 행동을 마치면 **딜러 턴 진행 / 판정**을 누릅니다. 이미 설정한 패를 바로 비교하려면 **현재 패 승패 판정**을 사용합니다.
5. 각 참가자의 **보유 칩**을 직접 수정할 수 있습니다(기본 100). 승패 판정 시 일반 승리는 베팅액만큼 증가, 패배는 베팅액만큼 감소, 푸시는 변동 없음, 내추럴 블랙잭 승리는 베팅액의 1.5배만큼 증가합니다. 더블은 베팅액을 2배로 적용합니다. 이미 정산한 판은 다시 정산되지 않습니다.
6. **결과 복사** 또는 **전체 기록 복사**로 RP에 전달할 텍스트를 얻습니다.

## 규칙 및 제약

- 52장 단일 덱의 중복 없는 카드 배치와 무작위 드로우.
- 딜러는 소프트 17을 포함해 합계 17 이상에서 멈춥니다.
- 점수, 블랙잭, 버스트, 승패 및 푸시(무승부)를 계산합니다.
- 자동 선택은 편의용 간단한 판단이며 완전한 기본 전략표는 아닙니다.
- 스플릿, 보험, 서렌더, 잔액 관리, 멀티덱, 사이드베팅은 아직 지원하지 않습니다.
- 칩 잔액은 판 사이에 유지되며, 정산 시 순손익만 반영됩니다. 베팅 시점에 칩을 미리 차감하지 않는 방식입니다.
- 상태는 브라우저 로컬 저장소에 저장됩니다. 실행 취소 이력은 새로고침하면 사라집니다.
- 클립보드 API는 HTTPS 등의 보안 컨텍스트가 필요할 수 있습니다.

`index.html` 하나에 UI, 임시 CSS 카드, 블랙잭 로직, 저장, 복사 기능을 넣었습니다. 외부 이미지 라이브러리는 필요 없습니다.

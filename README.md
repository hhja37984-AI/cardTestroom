# Card Testroom

RP 장면을 위한 모바일 카드/카지노 샌드박스. **모바일 화면을 좌우로 스와이프**해 블랙잭과 유럽식 룰렛 사이를 이동합니다. 게임별 상태는 독립적으로 브라우저에 저장됩니다. LLM의 자연어 출력을 자동 해석하지 않고 수동으로 장면의 패·결과를 지정할 수 있습니다.

## 실행 / 배포

정적 웹앱입니다. GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.

- `index.html`: 두 페이지 구조
- `style.css`, `blackjack.js`: 블랙잭 UI / 엔진
- `roulette.css`, `roulette.js`: 룰렛 UI / 엔진
- `navigation.js`: 모바일 스와이프에 따른 페이지 표시

## 블랙잭

기존 RP의 패를 직접 카드 추가/편집 버튼으로 설정하거나 새 패를 배분합니다. Hit / Stand / Double 또는 참가자의 자동 선택 1회로 진행한 뒤 딜러 턴과 승패를 판정합니다. 참가자별 칩을 관리하고 텍스트를 복사할 수 있습니다.

## 룰렛

유럽식 단일 0 룰렛(0~36)입니다. 휠 번호 순서는 실제 유럽식 순서를 사용합니다. 흰 공과 휠이 서로 반대 방향으로 회전하며, 결과를 미리 지정해도 해당 번호에서 멈춥니다.

1. 숫자 테이블을 눌러 단일 번호를 선택하거나 아래에서 베팅 종류를 고릅니다.
2. 참가자와 베팅 금액을 설정한 뒤 **베팅 추가**를 누릅니다. 여러 곳에 동시에 베팅할 수 있습니다.
3. 결과 지정은 선택 사항입니다. 빈 상태에서 **SPIN**을 누르면 무작위 0~36이 나옵니다.
4. 회전이 끝나면 자동 정산되고 최근 번호와 참가자별 손익이 표시됩니다. **결과 복사**로 RP용 텍스트를 가져갑니다.
5. **다음 판**에서 베팅만 초기화하고 잔액과 기록은 유지합니다.

지원 베팅: 단일 숫자(35:1), Split(17:1), Street(11:1), Corner(8:1), Six Line(5:1), 빨강/검정·홀짝·1~18/19~36(1:1), Dozen/Column(2:1). Split은 같은 줄의 좌우 인접 칸 또는 위아래 인접 칸을 지정합니다. Street·Six Line은 해당 줄의 첫 번호를 입력합니다. Corner는 네 칸 중 좌측 아래/시작 번호를 입력합니다.

**칩 계산**: 베팅 접수 시 금액을 잔액에서 예약(차감)하고, 당첨 시 원금과 배당금을 반환합니다. 베팅을 취소하면 예약 칩이 돌아옵니다. 룰렛 결과 확률은 각 칸 동일(1/37)이며, 공 애니메이션은 결정된 결과를 시각화하는 연출입니다.

## 참고

- 브라우저 로컬 저장소에 게임별 상태가 기록됩니다. 캐시/사이트 데이터를 지우면 기록이 사라집니다.
- 블랙잭의 실행 취소 이력은 새로고침 시 초기화됩니다.
- 클립보드 버튼은 HTTPS 환경을 권장합니다.
- 실제 화폐를 사용하는 서비스가 아닌 창작용 도구입니다.

게임 안내

게임 규칙은 일반적인 블랙잭 기준입니다. 딜러는 17 이상에서 멈추며 소프트 17에서도 스탠드합니다. 보험·스플릿·서렌더는 초기 버전에서 제외했습니다.

RP용 진행 정보

진행 기록

    카드를 누르면 편집할 수 있습니다. + 버튼은 직접 카드를 추가합니다. 모든 카드는 한 덱(52장)을 공유하며, 중복 카드는 허용되지 않습니다. 결과는 브라우저에 자동 저장됩니다. 승리 +베팅금, 패배 -베팅금, 무승부 0, 내추럴 블랙잭 +1.5배를 정산합니다. 실제 돈을 사용하지 않는 서사용 도구입니다.

    European Roulette

    칩을 놓고, 공을 굴리고, 서사에 필요한 결과만 복사하세요.

    베팅 접수 중

    결과를 지정하면 애니메이션은 해당 번호에서 멈춥니다. 비워두면 0~36 중 무작위로 굴립니다.

    베팅 테이블

    숫자를 누르면 단일 번호 베팅이 선택됩니다. 아래에서 다른 베팅 종류도 설정할 수 있습니다.

    순이익 배당 35:1

    참가자 · 칩 잔액

    베팅할 때 칩을 예약하고, 당첨되면 원금과 배당금을 반환합니다. 각 참가자의 잔액을 직접 수정할 수도 있습니다.

    최근 당첨 번호

    RP용 결과

    유럽식 단일 0 룰렛. 슬롯별 확률은 동일하며 휠 애니메이션은 이미 정해진 결과를 시각화합니다. 결과 수동 지정이 가능하고, 게임 기록은 이 브라우저에 보관됩니다.

    카드 선택

    기존 카드를 수정하거나 새 카드를 배치합니다.
